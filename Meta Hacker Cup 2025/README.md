# Meta Hacker Cup 2025

This repository contains my solutions for the Meta Hacker Cup 2025 programming competition.

## About Meta Hacker Cup

The Meta Hacker Cup is an annual international programming competition hosted by Meta Platforms. Participants solve a series of algorithmic problems in a fixed time, using a programming language and development environment of their choice. The competition consists of multiple online rounds, culminating in a final round where the winner is crowned.

## Repository Structure

This repository is organized by rounds, with each round having its own directory. Within each round's directory, there are subdirectories for each problem.

```
/
├── Practise_Round/
│   ├── problem1.py
│   ├── input.txt
│   └── output.txt
│
├── Round_01/
│   ├── Problem 1/
│   │   ├── problem.py
│   │   ├── input.txt
│   │   └── output.txt
│   ├── ...
│
├── ...
```

*   `problem.py`: The Python source code for my solution to the problem.
*   `input.txt`: The input data for the problem.
*   `output.txt`: The output generated by my solution.

This structure helps to keep the solutions organized and easy to navigate.
