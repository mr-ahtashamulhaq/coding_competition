# The Class Clown

## Problem
This puzzle presents a series of joke setups without punchlines, along with an image of various fruits.

We are given:
- Several incomplete jokes
- A collection of fruits shown in an image

The goal is to complete each joke and extract a final answer.

---

## Approach

### 1. Identify the Fruits
From the image, the fruits include:
- Melon  
- Banana  
- Dragon fruit  
- Papaya  
- Jagua  
- Nance  
- Longan  

These act as the base words for the puzzle.

---

### 2. Complete the Joke Punchlines
Each joke resolves into a phrase that sounds like one of the fruits.

Example:
- Joke: What would FIDE do if a chess streamer was cheating?  
- Punchline: **Ban Anna**  

This sounds like **banana**, but includes an extra letter.

---

### 3. Extract the Extra Letter
Each punchline differs from its corresponding fruit by exactly one extra letter.

Example:
- Banana → Ban Anna → extra letter: **N**

Repeat this process for all jokes.

---

### 4. Collect and Combine Letters
Gather all extra letters in order.

These letters form the final answer:
NETWORK

---

## Notes
- The core idea is phonetic matching between punchlines and fruit names  
- Each joke hides exactly one extra letter  
- Some fruits (like jagua) are intentionally obscure to increase difficulty  
- The challenge is both solving the joke and spotting the transformation
