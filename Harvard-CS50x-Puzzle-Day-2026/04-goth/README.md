# The Goth

## Problem
This puzzle presents a set of cryptic-style clues, each containing a marked position (X) within the answer.

We are given:
- Multiple clues that resolve to words
- Each word has a specific letter position marked (X)
- A set of categories that group the clues into pairs

The goal is to use these clues and categories to extract a final answer.

---

## Approach

### 1. Solve Clues and Extract Letters
Each clue resolves to a word. From each word, extract the letter at the marked (X) position.

Examples:
- "Something in the eye of the beholder" → **beauty** → extract **u**  
- "Deep gorge" → **canyon** → extract **n**  

Collect all extracted letters.

---

### 2. Pair Clues Using Categories
The clues are grouped into pairs based on given categories.

Each pair corresponds to phrases of the form:
- **Black + word**
- **White + word**

Example:
- Category: Anthology shows  
  - Black Mirror  
  - White Lotus  

Each pair uses two extracted letters from the corresponding clues.

---

### 3. Find the Midpoint Letter
For each pair of extracted letters:
- Convert both letters to their alphabetical positions  
- Find the letter exactly between them  

Example:
- R (18) and T (20) → midpoint is S (19)

Repeat this for all pairs.

---

### 4. Form the Final Word
Combine all midpoint letters in order.

This spells:
SCHEMATIC

---

## Solution
SCHEMATIC

---

## Notes
- The puzzle combines clue solving, grouping, and letter manipulation  
- The key step is recognizing the "black/white" pairing pattern  
- The final extraction depends on alphabetical positioning, not direct reading
