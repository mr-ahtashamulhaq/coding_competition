# The Prom (Meta Puzzle)

## Problem
This is the final meta puzzle that combines all previous puzzles.

We are given:
- Nine students (each representing a previous puzzle)
- Multiple attributes:
  - GPA rankings (1–9)
  - Favorite classes
  - Future schools
- A set of logic constraints connecting all attributes

The goal is to solve the full logic puzzle and use the results to extract a final answer.

---

## Approach

### 1. Solve the Logic Grid
This is a standard logic puzzle.

Assign for each student:
- GPA rank  
- Favorite class  
- University  

Using the constraints:
- GPA ordering relationships  
- Class and school pairings  
- Relative comparisons between students  

This produces a complete mapping of all nine students.

---

### 2. Connect to Previous Puzzle Answers
Each student corresponds to one earlier puzzle and its final answer:

- Band Geek → GOSPEL ALBUM  
- Class Clown → NETWORK  
- Foreign Exchange Student → SHORELINE  
- Goth → SCHEMATIC  
- Jock → BLUE JAYS  
- Nerd → DEWGONG  
- Rebel → OPPOSITION  
- Slacker → WORKMANSHIP  
- Theatre Kid → CAESAR  

These answers are used for extraction.

---

### 3. First Extraction (Class Matching)
Each student's favorite class matches the **length** of their puzzle answer.

Process:
- Align class name with corresponding answer  
- Find the **single overlapping letter in the same position**  

Order results by GPA rank (1 → 9)

This produces:
HE COOKS ST

---

### 4. Second Extraction (Hidden Indices)
Each university name hides a number (1–9).

Process:
- Extract the hidden number from each university  
- Use it as an index into the corresponding puzzle answer  
- Again, follow GPA order  

This produces:
AIMED HAMS

---

### 5. Combine the Results
Combine both phrases:

HE COOKS ST + AIMED HAMS  
→ HE COOKS STEAMED HAMS  

The puzzle also hints at the structure:
2-5-7-4 word lengths

---

### 6. Final Interpretation
"Steamed hams" is a reference to a famous scene from *The Simpsons*.

This leads to:
Principal Skinner

---

## Solution
PRINCIPAL SKINNER
