# CALICO Informatics Competition - Fall 2025

This repository contains the problems, sample data, and solution templates for the CALICO Fall 2025 programming competition, hosted by students at UC Berkeley.

## About CALICO

**CALICO** (formerly California Informatics Competition) is a biannual international programming competition. Its mission is to promote the understanding of algorithms and help students grow their problem-solving skills.

The Fall 2025 competition consists of 12 problems of varying difficulty, designed to be solved by teams. This repository serves as an archive of the contest materials.

## Repository Structure

The repository is organized into directories, one for each problem. Each problem directory contains:

-   `problem_name.pdf`: The problem statement, including introduction, input/output format, and constraints.
-   `data/sample/`: A directory with sample input (`.in`) and corresponding correct output (`.ans`) files.
-   `templates/`: A directory containing starter code for the problem in various supported languages (C++, Java, Python, etc.).
