# 🧠 M(IT)² Informatics 2025

### 🚀 A collection of algorithmic challenges solved with clarity and structure

Welcome to **M(IT)² Informatics 2025**.
This repo gathers problems from the MIT Informatics ecosystem puzzles built around logic, geometry, number theory, combinatorics, data structures, and strange Busy Beaver antics.

Here’s the thing. Informatics isn’t about memorizing formulas. It’s about thinking. You look at a problem, break it down, and make the machine say yes. This repository is my record of that process.

---

## 📚 What You’ll Find Here

Every problem sits in its own folder.
Inside that folder:

* 🧩 **main.py** — my solution
* 📄 **README.md** — the original problem statement, formatted cleanly

No clutter. No noise. Just problem → explanation → code.
